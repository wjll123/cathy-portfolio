# Cathy Photography - Everest Base Camp Journey

A photography portfolio documenting an 11-day trek to Everest Base Camp.

## Deployment

This site is built with Vite + React and deployed on GitHub Pages.

## Local Development

```bash
# In the source directory (cathy-v3)
npm install
npm run dev
```
